# Changelog

## 0.1.1

- Preserve incremental texture upload, request policy, JSON naming, and logging suppression when adapting requests.
- Require API 2.1.1 for the explicit display-only texture transport option.

## 0.1.0

- Added API texture, text, and byte media loaders.
- Added request cloning so response-format adaptation does not mutate caller state.
- Added cancellation, failure, and explicit resource-ownership mapping.
